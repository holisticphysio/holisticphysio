SETTING UP CLAUDE CODE WITH GITHUB
==================================


STEP 1: INSTALL CLAUDE DESKTOP
------------------------------

Download from claude.ai or your app store.
Sign in with your Anthropic account.


STEP 2: SET UP SSH AUTHENTICATION WITH GITHUB
---------------------------------------------

Open Terminal and run:

    ssh-keygen -t ed25519 -C "your@email.com"

Press Enter through the prompts (no passphrase needed for automated use).

Copy your public key:

    cat ~/.ssh/id_ed25519.pub

Go to GitHub > Settings > SSH and GPG keys > New SSH key, paste it.

Test the connection:

    ssh -T git@github.com

You should see:

    Hi [username]! You've successfully authenticated...


STEP 3: CLONE YOUR REPO LOCALLY
-------------------------------

    cd ~/Documents          # or wherever you want it
    git clone git@github.com:your-username/your-repo.git
    cd your-repo


STEP 4: OPEN IN CLAUDE CODE
---------------------------

Open Claude Desktop.
Click the Code tab.
Click Open Folder.
Select your cloned repo folder.


STEP 5: ASK CLAUDE CODE TO WRITE AND COMMIT
-------------------------------------------

Example prompt:

    Create a file called index.md with "# Hello World"
    Then commit and push it to main with message "Initial commit"

Claude Code will:

    - Write the file
    - Run git add index.md
    - Run git commit -m "Initial commit"
    - Run git push origin main

That's it. Your changes are now on GitHub.
